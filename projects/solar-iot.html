Solar IoT Model

IN PROGRESS

A compact solar-powered IoT model using an ESP32, solar panel, battery pack, relay isolation and remote control.

ESP32-WROOM5V 1A panel5V batteryRelay

Core idea

Use a small solar panel and battery source to power an ESP32-controlled load, with isolation between the controller and the load path. The system is designed around simple, understandable hardware blocks.

Planned controls

  • WeChat Mini Program control
  • Relay isolation for the load
  • Diode / protection considerations
  • 5V power path

Status

Hardware selected
Firmware / control ongoing
