# CrystalClearX Lab

Retro 1990s / early-2000s web portal meets Frutiger Aero glass UI.

## Files
- `index.html` — home
- `projects.html` — clickable project archive
- `projects/` — individual project pages
- `style.css` — retro glass UI
- `app.js` — project filters
- `_headers` — security headers
- `assets/logo.svg` + `favicon.svg` — CrystalClearX glossy icon

## Design direction
Late-1990s web structure: fixed-width portal layout, beveled controls, status lights, counters, ticker, nostalgic typography.

Frutiger Aero layer: bright sky, water, glossy glass, bubbles, soft gradients, reflective UI and optimistic “future” mood.
