# CrystalClearX Lab

A lightweight personal technology lab built with plain HTML, CSS and JavaScript, deployed as Cloudflare Workers Static Assets.

## v3 highlights
- Red / orange / warm-white visual system
- Clickable Projects index and project detail pages
- Real hardware photographs from Wikimedia Commons
- Local CrystalClearX favicon and icon
- Security headers via `_headers`
- Mobile-friendly layout and project filters
